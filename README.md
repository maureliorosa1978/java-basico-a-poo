# Java do Básico a Programação Orientada a Objetos.

Você deverá praticar os conceitos vistos nas aulas de Java resolvendo uma lista de exercícios que vai do básico da linguagem até os fundamentos de POO em Java.

### Objetivo
Consolidar o aprendizado de Java por meio da implementação prática dos exercícios.

Utilizar o GitHub como ferramenta de versionamento e entrega de código.

Desenvolver disciplina em registrar o progresso por meio de commits.

## Instruções
Clone o repositório disponibilizado pelo professor.

Esse repositório já contém a lista de exercícios cadastrada como issues numeradas.

### Para cada exercício:

* Implemente a solução em Java.

* Faça commits claros e descritivos (ex: Implementação do Exercício 01 - Hello World).

* Marque a issue correspondente como concluída.

* Ao finalizar todos os exercícios, envie o link do seu repositório no GitHub como entrega final.

### Exercícios

A lista de exercícios abrange os seguintes tópicos:

1. Estruturas condicionais (if/else e switch).
2. Estruturas de repetição (for, while, do-while).
3. Vetores e manipulação de arrays.
4. Criação e uso de métodos.
5. Modularização simples de código.
6. Introdução à Programação Orientada a Objetos.
7. Criação de classes e objetos.
8. Atributos e métodos em classes.
